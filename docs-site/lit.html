    Generate Lit SVG web components

    Lit output creates web component source. The consuming project must provide Lit and a browser-compatible build environment.

    npx svger build ./icons ./src/icons --framework lit --typescript
npx svger build ./icons ./src/icons-js --framework lit --no-typescript

    Validate custom-element names, shadow DOM styling, attributes, accessibility semantics, and browser support in the application. Test generated components in the actual target browsers.

    See input safety and troubleshooting.

    Related source and version caveats: SVGER-CLI repository.
