    Generate Svelte SVG components

    SVGER-CLI writes .svelte component files. The legacy generator remains the default; the source candidate also has an explicitly selected static IR-v1 path for supported cases.

    Default generation

    npx svger build ./icons ./src/lib/icons --framework svelte --typescript

    Use --no-typescript for JavaScript components. Compile output with the Svelte toolchain in the consuming project.

    Explicit IR-v1 opt-in

    There is no dedicated CLI switch. Set svelteCompiler: "ir-v1" in .svgconfig.json or call the public compiler API with that option. Unsupported static constructs are rejected rather than silently falling back. This is not a claim of full dynamic-Svelte, CSS-cascade, browser rendering, or accessibility equivalence.

    { "framework": "svelte", "typescript": false, "svelteCompiler": "ir-v1" }

    Read the compiler limits and live benchmark methodology before comparing modes.
