    Generate Angular SVG components

    Angular generation requires TypeScript; JavaScript output is not supported for this target. The CLI creates source components and does not replace Angular workspace configuration.

    npx svger build ./icons ./src/app/icons --framework angular --typescript --standalone

    Use --standalone when appropriate for the target application. Compile with the app's Angular CLI and verify generated imports and metadata in that workspace.

    Module-based applications

    Omit --standalone when the output is intended for a module-oriented setup, then register components according to that application's architecture. Validate selectors, naming collisions, and accessibility behavior.
