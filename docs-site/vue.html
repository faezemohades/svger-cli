    Generate Vue 3 SVG components

    Vue output uses .vue single-file components. Select Composition API script setup or the default component style where offered.

    Composition API

    npx svger build ./icons ./src/icons --framework vue --typescript --composition

    JavaScript output

    npx svger build ./icons ./src/icons --framework vue --no-typescript --composition

    Compile generated files with the Vue compiler version and bundler used by your app. Check component naming, props, SVG accessibility semantics, styling assumptions, IDs, and resource references in the generated output.

    Build integration

    Use the Vite or Webpack integration guide for build-time imports. See configuration precedence for persistent framework defaults.
