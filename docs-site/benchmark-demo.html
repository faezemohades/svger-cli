🧪 How to Test

Option 1: Sample SVGs (Quick Test)

  1. Open the live benchmark/evidence section from the documentation site
  2. Select framework (React, Vue, Angular, Svelte)
  3. Keep "Sample SVGs (10 icons)" selected
  4. Click "Run Benchmark Test"
  5. Watch real-time progress and results

Option 2: Upload Custom SVGs

  1. Switch to "Upload Your SVGs" mode
  2. Drag & drop SVG files or click to browse
  3. Verify file count and size display
  4. Click "Run Benchmark Test"
  5. Export results as JSON for record-keeping

💻 Technical Details

The benchmark system simulates SVGER-CLI's SVG processing pipeline:

  • File Processing: Reads SVG content and parses structure
  • Component Generation: Applies framework-specific templates
  • Performance Tracking: Uses Performance API for accurate timing
  • Real-Time Updates: Progress bar and status indicators
  • Export Feature: Blob API for JSON download
📌 Note: This is a browser-based simulation. Actual CLI performance may vary based on system resources and file complexity. For production benchmarks, see our real-world test results.
