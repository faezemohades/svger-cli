# Performance and comparison claim policy

SVGER performance comparisons must name the fixture, runtime, host, exact build identity, and
measurement method. No competitor advantage or fixed percentage is claimed here. The older broad
comparison material is retained only in historical reports and should not be presented as current
evidence.

The currently documented Phase 04.4 Svelte numbers are local historical observations on one
synthetic workload. They are not a promise for other SVGs, hosts, runtimes, or frameworks. The
fixture count is 750 groups and 2,251 XML elements (root plus three elements per group).

Use [`BENCHMARK_TESTING.md`](BENCHMARK_TESTING.md) for the local evaluator. It runs only after an
explicit command; docs pages do not start tests, benchmarks, or network requests.
