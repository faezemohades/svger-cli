    Generate React SVG components

    React output is generated as JavaScript or TypeScript component source. Install React and its compiler in the consuming application; SVGER-CLI does not add them as runtime dependencies.

    TypeScript TSX

    npx svger build ./icons ./src/icons --framework react --typescript

    JavaScript JSX

    npx svger build ./icons ./src/icons --framework react --no-typescript

    Use components with standard React imports from generated files. Check the output against your JSX runtime, lint rules, accessibility requirements, and the React version in your application. Review viewBox, title/label behavior, IDs, gradients, and references for each icon set.

    Single icon

    npx svger generate ./icons/search.svg ./src/icons --framework react --typescript

    For shared build pipelines, see Vite, Webpack, Rollup, Babel, Next.js, and Jest integration examples. For all framework outputs see the framework overview.
