    SVG to component documentation

    SVGER-CLI converts admitted SVG files into source components for React, React Native, Vue, Angular, Svelte, Solid, Preact, Lit, and browser-native JavaScript.

    Release status: package 4.1.0 is planned and unpublished. This site documents source behavior; it is not a release notice or npm availability guarantee.

    Start with a workflow

    Install the CLI, select a target framework, build a directory, and compile the generated files in the consuming application. SVGER generates source; it does not install framework runtimes.

    npm install --save-dev svger-cli
npx svger build ./icons ./src/components/icons --framework react --typescript

    Choose a framework

    • React and JSX · React Native · Vue 3
    • Angular · Svelte · Solid
    • Preact · Lit · Vanilla DOM

    What the benchmark does—and does not—claim

    GitHub Pages cannot measure the CPU and resident memory of local Node processes. The benchmark page connects only after you start its loopback companion; metrics come from fresh local Node child processes. Results are host-specific and may favor either implementation. No preselected winner or synthetic result is displayed.
