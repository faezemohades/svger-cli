SVGER-CLI · planned 4.1.0 documentation

Generate framework components from SVG files

SVGER-CLI is a Node.js command-line tool and library for generating typed or JavaScript components from SVG input.

Release status: 4.1.0 is a planned, unpublished version. The release remains NO-GO; this documentation update does not authorize publication.

Install and build

npm install svger-cli
npx svger build ./icons ./components

The package declares Node.js ≥18.17. See the command reference for language and framework options.

Framework targets

Production generation targets React, Preact, Solid, Vue, Svelte, Angular, Lit, Vanilla, and React Native. JavaScript and TypeScript support varies by framework; unsupported combinations return diagnostics. Svelte’s experimental IR emitter is opt-in and the legacy route remains the default.

Webpack, Vite, Rollup, Babel, Next.js, and Jest integrations are available through documented package subpaths. See compiler modes and limits.

Measured performance

The latest local evaluation (Node.js 22.22.2 / npm 10.9.7) measured a 750-group, 2,251-element Svelte fixture at 10.086 ms legacy median and 75.562 ms opt-in IR median (about 7.5× slower); p95 was 12.426 ms and 85.575 ms. A separate Node.js 20.20.2 run measured 10.768 ms legacy and 77.829 ms IR. These are host-specific observations, not performance guarantees or evidence to change the production default.

Re-run the configurable, opt-in evaluator using the evaluation guide. Nothing is benchmarked by opening this site.

Security and limitations

SVG input is admitted by the security boundary before generation. External references, active content, malformed XML, and configured resource-limit violations are rejected by default. Static SVG support does not imply full browser rendering equivalence. Read the package’s optional dependency guide and support matrix.
