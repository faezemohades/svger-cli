Generation behavior

Compiler modes and limitations

Production path

The stable generation route retains the legacy source-based framework generators. Basic cleaning and numeric formatting are part of the normal processing path; optional optimizer modules are not implicitly reactivated by the Svelte IR work.

Svelte IR opt-in

Svelte supports an explicitly selected ir-v1 compiler mode through the programmatic/configuration contract. The legacy generator remains the default. The opt-in path is bounded and does not change other framework routes.

Optimization is not semantic proof

Transformations may change lexical SVG representation. Security admission, semantic preservation checks, generated-language validation, and compatibility evidence are separate concerns. Pixel similarity alone does not prove text, references, accessibility, or runtime equivalence.

For measured local comparisons, use the opt-in evaluation instructions. This page performs no benchmark or code execution.

Known boundaries

  • Experimental IR emitters for frameworks other than Svelte are not production routes.
  • Static SVG analysis is bounded and may report partial/unresolved coverage for unsupported syntax.
  • Visual rasterization is optional and requires separately installed compatible dependencies; see the optional dependency guide.
