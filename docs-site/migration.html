    Migration and compatibility guide

    Before migrating, commit existing configuration and generated output, then run a preview. This project maintains a compatibility baseline; do not assume planned changes are published.

    svger migrate config .svgconfig.json --dry-run
svger migrate config .svgconfig.json

    Migration targets include configuration, plugin declarations, and import forms. Backups are created by default for supported migrations. Review the report before accepting changes.

    Deprecated options

    V4 aliases such as --src, --out, and older naming flags may emit deprecation warnings. Prefer positional source/output arguments and configuration keys documented by the installed version.

    Version differences

    The documentation source may describe an unpublished candidate. Check svger --version, the package changelog, and the compatibility matrix before relying on new flags. See the migration guide.
