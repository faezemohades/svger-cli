    SVGER-CLI configuration guide

    SVGER reads .svgconfig.json from the working directory. Command options and project config combine into effective settings; inspect origins with config --explain.

    npx svger config --init
npx svger config --set framework=vue
npx svger config --set typescript=false
npx svger config --set outputConfig.naming=kebab
npx svger config --explain framework --format json

    Example configuration

    {
  "framework": "react",
  "typescript": true,
  "optimizationLevel": "basic",
  "recursive": false,
  "outputConfig": { "naming": "pascal" }
}

    Use options supported by the installed version. Keep environment-specific paths in command invocations rather than sharing private machine paths in committed configs.

    Reproducibility and discovery

    Hidden files are skipped and symlinks ignored by default. Set recursive/include/exclude rules deliberately; enforce sensible file-count and input-size limits. Default output-name collisions fail so you can resolve ambiguous names explicitly.

    See CLI options, optimization levels, and security policy.
