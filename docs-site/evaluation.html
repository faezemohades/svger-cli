Evaluate a local build

This static page does not execute a compiler, run a benchmark, or fetch a report. Evaluation runs only when you explicitly invoke the command in a trusted local checkout. 

npm run build
npm run evaluate:local -- --groups 50,750 --warmups 8 --samples 40 --output ./evaluation.json

The tool compares Svelte legacy and opt-in IR generation, validates generated Svelte, checks repeatability and semantic projections, runs the Phase 04 compatibility suite and non-destructive security regressions, and records fixture/build/runtime metadata. Security results cover only those listed regression suites; they are not comprehensive security certification and produce no security score. Semantic coverage is shown separately from quality checks. Timing and memory values are informational.

For two local builds, pass --before-build DIR --after-build DIR. Those package roots need package.json and dist/index.js; the evaluator imports and executes them directly, without sandboxing. Use only builds you trust; do not benchmark untrusted code.

View a report

Reports are unsigned, self-reported local evidence. Schema validation does not authenticate who or what produced a report. Performance comparisons across reports are descriptive only because host load, hardware, runtime, build identity, and fixture settings may differ.
