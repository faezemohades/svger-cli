    SVGER-CLI plugin guide

    Plugins extend processing hooks and run in the same process as SVGER-CLI. A plugin is executable code with the permissions of the invoking user—there is no plugin sandbox.

    Load a plugin

    svger plugins
svger plugins --load ./plugins/my-plugin.js
svger build ./icons ./out --plugin optimize,minify

    Only install or load plugins from sources you trust. Pin versions and review transitive packages; do not treat a plugin name or TypeScript type as a security boundary.

    Development

    Implement declared hooks, validate plugin metadata, avoid ambient network/filesystem access unless necessary, and return bounded diagnostics. Test hook ordering, errors, cleanup and repeated builds. See the plugin development guide for types and lifecycle contracts.

    Operational boundary

    Plugins receive no separate OS identity and are not isolated from the CLI. For high-risk untrusted plugin code, do not load it in a process containing credentials or sensitive paths.
