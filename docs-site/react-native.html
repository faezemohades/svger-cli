    Generate React Native SVG components

    React Native output uses React Native SVG primitives. The consuming application must install and configure react-native-svg; generated source alone does not provide that runtime.

    npx svger build ./icons ./src/icons --framework react-native --typescript

    Use --no-typescript for JavaScript output when supported by the target configuration.

    Validate in the actual app

    Native renderers differ from browser SVG. Compile with the app's React Native toolchain and test representative icons on supported platforms. Check gradients, masks, clipping, text, external references, and unsupported SVG features rather than assuming browser support maps exactly to native output.

    Security and asset handling

    SVG input is admitted before generation. External references are restricted by default. Review the security guide and framework overview.
