    SVGER-CLI troubleshooting

    CLI not found

    Install the package in the project, then use npx svger --help or the local package manager's executable path. Check that Node.js and npm are available.

    Unsupported framework option

    Use one of the accepted framework identifiers listed on the framework page. For exact behavior, consult the installed CLI's help output.

    Unsafe SVG rejected

    Review the diagnostic and source. Prefer correcting/removing unsafe external references or active markup. Strip mode is an explicit lossy policy, not a general sanitizer.

    Output collision

    Two input names may map to the same output component name. Rename source files or select a documented collision policy deliberately; default behavior fails rather than silently overwriting.

    Generated component fails framework compilation

    Verify the framework version, TS/JS mode, framework-specific dependencies, and integration options. Compile in the target application and share a minimal sanitized fixture when requesting help.

    Live benchmark cannot connect

    Start the local companion after building the repository and installing its benchmark-only dependencies. Keep it on the loopback address and allow the documented Pages origin. No hosted server is provided by GitHub Pages.

    Related source and version caveats: SVGER-CLI repository.
