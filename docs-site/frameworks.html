    Framework support overview

    SVGER-CLI generates source files for nine target families. Install framework runtimes separately, then compile and test generated files in the consumer application.

    TargetCommon outputKey noteGuide
    ReactJSX / TSXCompile with your app's React toolchainReact guide
    React NativeJSX / TSXRequires react-native-svg in the appReact Native guide
    Vue.vueComposition API option availableVue guide
    Angular.component.tsTypeScript requiredAngular guide
    Svelte.svelteLegacy remains defaultSvelte guide
    SolidJSX / TSXValidate with the Solid compilerSolid guide
    PreactJSX / TSXUse Preact's JSX runtimePreact guide
    Lit.js / .tsWeb component outputLit guide
    Vanilla DOM.js / .tsRequires browser DOM at runtimeVanilla guide

    TypeScript is selected by default where supported. Use --no-typescript for JavaScript. Unsupported combinations return diagnostics instead of silently selecting another framework.

    Framework compiler and runtime conformance depends on the support matrix and version; see runtime guidance and troubleshooting.

    Related source and version caveats: SVGER-CLI repository.
