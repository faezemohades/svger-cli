    Install SVGER-CLI

    SVGER-CLI is installed as a project tool. It emits component source but does not bundle React, Vue, Angular, Svelte, or other framework runtimes into your application.

    Install from npm

    npm install --save-dev svger-cli
npx svger --version
npx svger --help

    Package publication is controlled independently from this documentation. Check the npm registry for the version currently available to your account.

    Runtime compatibility

    Use the Node.js release table and the package's support matrix when selecting a runtime. The declared compatibility floor and currently security-supported Node releases are different concepts.

    Optional visual validation

    Raster-based --validate is optional and needs compatible separately installed packages. Ordinary source generation does not require the rasterizer. See optional dependency requirements before enabling it in CI.

    Development checkout

    Repository-only tests, benchmark tools, and the SVG sample corpus are not runtime dependencies. The sample corpus is maintained for project testing and is intentionally excluded from the npm package.
