    SVGER-CLI command reference

    The binary names are svger and svger-cli. Use the installed version's help output as the authority for the command surface.

    svger --help
svger build <src> <out> --framework react --typescript
svger generate ./icons/search.svg ./src/icons --framework svelte
svger watch ./icons ./src/icons

    Build options

    --framework selects react, react-native, vue, angular, svelte, solid, preact, lit, or vanilla. TypeScript is the default where supported; use --no-typescript for JavaScript. Vue supports --composition, Angular supports --standalone. Builds also accept optimization, validation, include/exclude globs, recursion, hidden-file and symlink policies, collision policy, concurrency, file-count limits, dry-run/check/diff modes, and report formats.

    Maintenance

    svger optimize ./icon.svg ./out/icon.svg --level balanced
svger config --init
svger plugins
svger lock ./icons/logo.svg
svger unlock ./icons/logo.svg
svger recover ./src/icons --format json
svger migrate config .svgconfig.json --dry-run
svger clean ./src/icons

    clean removes generated files from the chosen directory. Check the path before running it. Plugins execute with the invoking user's process permissions; load only trusted code. Deprecated aliases may warn. Read the complete CLI reference source for exact flags and migration behavior.
