CLI and API

Commands

The binary names are svger and svger-cli. Use svger --help and svger <command> --help for the installed release's authoritative options. Version 4.1.0 is planned and unpublished; this page describes the documented source candidate, not an npm release.

Generate components

# Build a directory (top-level only by default)
npx svger build ./icons ./components --framework react --typescript

# Generate one file
npx svger generate ./icons/search.svg ./components --framework svelte --no-typescript

# Watch for changes; stop with Ctrl-C
npx svger watch ./icons ./components

Targets are React, React Native, Vue, Angular, Svelte, Solid, Preact, Lit, and browser-native vanilla output. Use --recursive for nested source folders and --no-typescript for JavaScript where supported. Angular generation requires TypeScript. See the repository's framework guide for target examples and caveats.

Preview and reporting

npx svger build ./icons ./components --dry-run
npx svger build ./icons ./components --check
npx svger build ./icons ./components --diff --format json

The three build modes are mutually exclusive. Build reports accept pretty, json, or ndjson. Output collisions fail by default; resolve names or explicitly choose a deterministic collision policy.

Configure and optimize

npx svger config --init
npx svger config --show
npx svger config --set framework=vue
npx svger config --explain framework --format json
npx svger optimize ./icon.svg ./optimized/icon.svg --level balanced

Optimization changes SVG source and does not establish semantic or pixel equivalence. Optional raster validation needs separately installed dependencies and Node.js >=20.9. Read the optional dependencies guide.

Maintenance and migrations

npx svger plugins
npx svger lock ./icons/logo.svg
npx svger unlock ./icons/logo.svg
npx svger recover ./components --format json
npx svger migrate config .svgconfig.json --dry-run
npx svger clean ./components

clean removes generated files from the selected output directory. Check the target before running it. Migrations preview with --dry-run and create backups by default. The repository's complete CLI reference documents every command, option, default, and caution.

Programmatic use

import { createSVGCompiler } from 'svger-cli';

const compiler = await createSVGCompiler({ cwd: process.cwd() });
const report = await compiler.build({
  src: './icons',
  out: './components',
  framework: 'svelte',
  typescript: false,
});

The public root facade provides build() and resolved configuration explanations. Check the installed package declarations for exact public types; internal compiler modules are not public imports.
