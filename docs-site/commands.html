CLI and API

Commands

Generate one SVG

svger generate ./icon.svg ./components

Build a directory

svger build ./icons ./components --framework svelte --typescript

Use svger --help or svger build --help for the installed version’s authoritative options. Output extension follows the selected language mode. Unsupported framework/language combinations fail with an actionable diagnostic.

Configuration

Use .svgconfig.json or the corresponding programmatic options. See the checked-in configuration example and framework guide. Security admission and transactional output handling apply across public generation paths.

Programmatic use

import { createSVGCompiler } from 'svger-cli';

const compiler = createSVGCompiler({ framework: 'svelte' });
const result = await compiler.processSVGFile('icon.svg', 'components');

See the published package declarations for the exact API of the installed release. This site describes a planned 4.1.0 candidate and is not a substitute for that package contract.

Integrations

Integration subpaths include svger-cli/vite, /webpack, /rollup, /babel, /nextjs, and /jest. Follow each tool’s own configuration and build lifecycle.
