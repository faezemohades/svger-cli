    SVGER-CLI programmatic API

    The public package root exports createSVGCompiler. It creates a scoped compiler service with build() and config.explain().

    import { createSVGCompiler } from 'svger-cli';

const compiler = await createSVGCompiler({ cwd: process.cwd() });
const report = await compiler.build({
  src: './icons',
  out: './src/generated/icons',
  framework: 'react',
  typescript: true,
});
console.log(report.status, report.artifacts.length);

    Request fields include source/output paths, framework, language, optimization, selection, concurrency and safety policy. Validate reports and handle failure status in the calling application. Internal compiler modules are not public imports; rely on declarations from the installed package.

    Configuration explanation
