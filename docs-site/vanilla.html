    Generate vanilla JavaScript SVG components

    Vanilla output uses standard browser DOM facilities instead of a component framework. Generated code still requires a browser DOM when executed.

    npx svger build ./icons ./src/icons --framework vanilla --typescript
npx svger build ./icons ./src/icons-js --framework vanilla --no-typescript

    Review output in the browser environment where it will run. Server-side Node execution without a DOM is not implied. Keep event handling, IDs, external resource policy, and accessibility labels in view.

    For framework output options, visit frameworks.
