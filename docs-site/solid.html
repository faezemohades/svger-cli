    Generate Solid SVG components

    Solid output is generated as JavaScript or TypeScript component source. Install Solid and its build tooling in the consuming app.

    npx svger build ./icons ./src/icons --framework solid --typescript
npx svger build ./icons ./src/icons-js --framework solid --no-typescript

    Build the generated source with the same Solid compiler and JSX settings as the application. Verify props, SVG attributes, references, and accessibility behavior with representative inputs.

    The --signals option is available on the build command for applicable generator behavior; consult svger build --help for the installed version. See configuration and commands.

    Related source and version caveats: SVGER-CLI repository.
