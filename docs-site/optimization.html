    SVG compiler and optimization limits

    Optimization rewrites SVG source; generation converts admitted input into framework syntax. Neither operation proves full browser behavior or pixel equivalence.

    Optimization levels

    Choose none, basic, balanced, aggressive, or maximum according to your tolerance for source changes. Preserve originals and validate output with your target renderer and application tests.

    Svelte IR-v1

    The experimental static IR emitter is an explicit opt-in for Svelte only. Legacy remains default. Other framework IR emitters remain experiments and are not production routes. Unsupported IR syntax fails closed; it does not silently fall back.

    Coverage boundaries

    Static SVG conversion is not a browser, CSS cascade engine, external-resource resolver, or universal semantic analyzer. Text, references, CSS, filters, masks, foreign content and accessibility can have nuanced behavior. Review the security policy and run target framework compilation.

    Benchmark interpretation

    Use live local benchmarks to compare actual transforms on your machine. This site does not promise SVGER is faster: it reports measured wall time, CPU time, sampled RSS, output bytes, and successes for both implementations.
