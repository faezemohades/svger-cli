    Getting started with SVGER-CLI

    This walkthrough takes an SVG folder to framework component files. Run commands from the consumer application's root so paths and configuration are predictable.

    1. Install the CLI

    npm install --save-dev svger-cli

    The package supports Node.js according to its declared engine range. Use a currently supported Node LTS for production; see installation and runtime guidance.

    2. Organize source icons

    Place trusted .svg files in a dedicated folder such as ./assets/icons. Keep originals in version control. The build discovers immediate children by default; use --recursive for nested folders.

    3. Generate one target

    npx svger build ./assets/icons ./src/components/icons --framework react --typescript

    Choose one of the supported output targets. The target framework and its compiler remain the consuming app's responsibility.

    4. Compile and inspect generated files

    Run the app's own TypeScript/framework build and tests. Review accessibility labels, IDs and references, CSS assumptions, dimensions, and the generated diff. A successful conversion is not proof of browser-rendering equivalence.

    5. Make the build repeatable

    Commit configuration and generated outputs only if that matches your project policy. Use --check in CI to detect stale generated artifacts, and --dry-run to preview without writing.

    npx svger build ./assets/icons ./src/components/icons --framework react --check --format json

    Continue to the command reference or configuration guide.
