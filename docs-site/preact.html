    Generate Preact SVG components

    Preact components are emitted as JSX or TSX source. Keep Preact, JSX transform settings, and any compatibility layer configured in the application itself.

    npx svger build ./icons ./src/icons --framework preact --typescript
npx svger build ./icons ./src/icons-js --framework preact --no-typescript

    Compile and render representative output with the project's Preact toolchain. Do not infer React runtime compatibility from syntactic JSX similarity.

    See bundler integrations and the framework overview.
